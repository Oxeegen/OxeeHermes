- **Based on Hermes Agent v0.22.5**: about 3,000 upstream improvements since 0.8.0, among them
  delegation routing for sub-agents, steadier gateway and backend start, and Bots fixes.
- **What's new in your language**: Settings › About shows these notes in the language of the
  interface when the release has them (French and English for now).
- **macOS**: an app for Apple silicon Macs, not signed yet (see Install).
- Releases are now built on GitHub, for Windows and macOS.

### Install

- **Windows**: download `OxeeHermesBundled-Setup-0.8.1-x64.exe` below and run it, or update from
  Settings › About in 0.8.0. The installer is not signed yet: SmartScreen shows a warning, click
  **More info**, then **Run anyway**.
- **macOS**: download the `.dmg` below and drag Oxee Hermes into Applications. The app is not signed
  yet: the first time, right-click it and choose **Open**. Later versions will have to be installed
  the same way, by hand, until it is signed.
