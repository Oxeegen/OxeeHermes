- **Updates in seconds** (from the next update on): when a release only changes part of the app,
  Oxee Hermes downloads just the changed files and prepares the new version while you keep working.
  **Install and restart** then swaps it in within seconds. Even if you skipped up to two releases,
  the update still downloads only the changed files. In any other case, the full installer runs as
  before. This update itself still goes through the full installer.
- **Descriptions in French**: skills and plugins show their descriptions in French when the app is
  in French. This covers the bundled skills and plugins, every plugin of the catalog and the skills
  of Hermes and of vendors such as NVIDIA, OpenAI or Anthropic. Skills from the community
  directories (ClawHub, skills.sh) stay in English.
- **Based on Hermes Agent 0.23.1** (previously 0.22.5), which brings, among others:
  - **Bots**: group chats get a purpose and shared notes. Scheduled jobs can post into them, a lead
    bot can route the conversation, and each member's live state is shown.
  - **Plugins**: **Update all** and an automatic update switch on the Plugins tab.
  - **Skills**: lock a skill from Capabilities so the agent can no longer change it.
  - **Scheduled tasks**: stop a running job, and choose what happens to runs missed while the
    computer was off.
  - **Kanban**: pin boards as tabs to switch between them quickly.
  - When the agent asks several questions at once, they come as a single form. A notification that
    arrives while the window is in the background makes its taskbar entry flash.
- **Plugins**: compatibility is now checked against Hermes 0.23.1, so plugins that require it
  install.

### Install

- **Windows**: download `OxeeHermesBundled-Setup-0.8.4-x64.exe` below and run it, or update from
  Settings › About. The installer is not signed yet: SmartScreen shows a warning, click
  **More info**, then **Run anyway**.
- **macOS**: download the `.dmg` below and drag Oxee Hermes into Applications. The app is not signed
  yet: the first time, right-click it and choose **Open**.
