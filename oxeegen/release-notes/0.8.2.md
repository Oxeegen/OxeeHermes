- **First launch fixed**: a new installation opens the Oxeegen form (region and API key) again. In
  0.8.1 it opened a guided chat instead, which failed with "The AI service rejected your sign-in"
  because no key was saved yet.
- **Max reasoning by default**: the Oxeegen models think at Max unless you pick another level in the
  Effort menu. A level you already chose is kept.
- **Bot Mode**: the notice shown while the gateway is not connected yet is translated.
- **Kanban on by default**: the multi-agent task board (Capabilities › Plugins) is active out of the box, with its sidebar entry. Switch it off there if you do not use it.

### Install

- **Windows**: download `OxeeHermesBundled-Setup-0.8.2-x64.exe` below and run it, or update from
  Settings › About. The installer is not signed yet: SmartScreen shows a warning, click
  **More info**, then **Run anyway**.
- **macOS**: download the `.dmg` below and drag Oxee Hermes into Applications. The app is not signed
  yet: the first time, right-click it and choose **Open**.
