- **Much faster updates**: installing an update takes a few minutes instead of about twenty. The
  components are now unpacked in one go instead of file by file.
- **Updates you can follow** (from the next update on): Oxee Hermes asks before closing
  (**Install and restart** or **Later**), then the installer shows its progress and relaunches the
  app by itself, without asking anything again.
- **Shortcuts and version kept right**: an update no longer loses the Start menu entry, and
  Windows' Installed apps list shows the version actually installed.
- **Plugins**: plugins that require a recent Hermes version install again. Oxee Hermes checks them
  against the Hermes release it is built on (0.22.5), not its own version number.
- **The agent introduces itself as Oxee Hermes**, Oxeegen's AI agent. An unmodified persona is
  updated automatically; one you customized is left as it is.
- **French**: the Capabilities catalog is translated, and the Messaging cards use the product name.
- Every release is now installed, updated and uninstalled on a clean Windows machine before it is
  published.

### Install

- **Windows**: download `OxeeHermesBundled-Setup-0.8.3-x64.exe` below and run it, or update from
  Settings › About. The installer is not signed yet: SmartScreen shows a warning, click
  **More info**, then **Run anyway**.
- **macOS**: download the `.dmg` below and drag Oxee Hermes into Applications. The app is not signed
  yet: the first time, right-click it and choose **Open**.
