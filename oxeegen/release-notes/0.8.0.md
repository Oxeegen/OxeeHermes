First public release of Oxee Hermes, Oxeegen's desktop AI agent.

- **Oxeegen, nothing to configure**: pick your region (Europe or US) and enter your Oxeegen key.
  The agent, its auxiliary tasks, speech-to-text and voice all run on Oxeegen; no other provider can
  be selected.
- **Oxeegen models**: Oxee Max, Pro, Ultra, Flash and Instant in the model menu.
- **Voice**: a fixed chain, Oxeegen speech-to-text → Hermes → Oxeegen voice. Configurable
  transcription language (the system language by default), 35 French voices (Chloé by default),
  answers read aloud.
- **French interface**, Bots included (tooltips, menus, new bots, context menu).
- **Side panel**: the Oxee Hermes logo at the left of the title bar; folded, the panel keeps the logo
  upright, aligned with "Sessions" and "Bots".
- **Settings**: Passwords & credentials, Plugins and Uninstall (translated); screen capture only
  shows on macOS.
- **Windows installer**: `setup.exe`, for the current user (no admin rights) or for all users; the
  `oxee-hermes` command on the PATH. Oxee Hermes keeps its own data folder and runs side by side with
  an official Hermes install.
- **Updates**: Settings › About shows what is new in the installed version and installs the next
  release from GitHub in one click.

### Install

Download `OxeeHermesBundled-Setup-0.8.0-x64.exe` below and run it. The installer is not signed yet:
Windows SmartScreen shows a warning, click **More info**, then **Run anyway**.
